# Sonus v1.0.0

Initial Global release of Sonus for Windows.

## Highlights

Sonus is a lightweight desktop YouTube audio player focused on simple playback without rendering YouTube video content.

### Included

- YouTube video and playlist support
- Music-oriented text search
- Search previews and titles
- Queue management across multiple sources
- Play / pause / previous / next
- Manual seek and 10-second seeking
- Volume control
- Background caching
- Three cache download modes: Streaming, Smart and Mixed
- Repeat queue and random playback
- Search result limit from 1 to 50
- Dark Sonus interface
- English and Russian interface languages
- Automatic first-run dependency setup on Windows
- Console-free application launch
- Automatic cache cleanup at startup
- One-time first-run legal notice and acknowledgement
- Streaming is the default cache mode

## Windows setup

Download the ZIP below, extract it and run `run_windows.bat`.

The launcher checks the required environment and installs missing Python dependencies automatically. Python 3.13 is used for compatibility with the current pygame dependency. FFmpeg is also checked during setup.

## Notes

This is the first public Global release. Expect some rough edges and report reproducible issues through GitHub Issues.

Sonus is not affiliated with YouTube or Google. Users are responsible for complying with applicable laws, copyright restrictions, creators' rights, and service terms when accessing content.

# Sonus v1.0.0 - Русский

Первый Global-релиз Sonus для Windows.

## Основное

Sonus - лёгкий настольный аудиоплеер YouTube, ориентированный на простое воспроизведение без отображения содержимого видео.

### Включено

- Поддержка видео и плейлистов YouTube

- Превью и названия результатов поиска

- Ручная перемотка и перемотка на 10 секунд
- Регулировка громкости
- Фоновое кэширование
- Три режима загрузки кэша: Потоковая, Умная и Смешанная
- Повтор очереди и случайное воспроизведение
- Настройка количества результатов поиска от 1 до 50
- Тёмный интерфейс Sonus
- Английский и русский языки интерфейса
- Автоматическая первоначальная установка зависимостей Windows
- Запуск приложения без постоянно открытой консоли
- Автоматическая очистка кэша при запуске
- Одноразовое юридическое уведомление при первом запуске
- Потоковая - режим кэширования по умолчанию

## Установка в Windows
